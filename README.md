# VocabFlash / 词汇自查 · v5 · 七张内置背景（每分钟随机）

这是现有 iPhone 主屏幕 PWA 的**背景专用更新版**，不是一个新的 App。基于 v4 修改；单词卡、自我测验、拼写训练、词库管理、搜索及 JSON 备份逻辑均保留。

## 本次改动

- 只内置用户最新提供的 **7 张图片**：两张皮卡丘 + 五张人物照片，按收到顺序保存为 `wallpaper-01.jpg` 至 `wallpaper-07.jpg`。
- 每张为 **900×1950 的 iPhone 竖屏 JPEG**。为了不改变人物/插画、文字与原始构图，主画面全部等比例保留；宽高比不合适的图片使用**同一图片模糊扩展的边缘**补足画布。没有生成新人像、擦除文字或修改图中内容。
- **默认每约 60 秒随机切换一次**，尽量不连续重复；打开应用随机一张，也可点「背景图片 → 立即换一张」。背景页另外保留「只在打开时随机」及「固定当前图片」选项。
- 不再读取和展示 v4 从手机相册上传的旧背景。升级时尝试删除专用于旧背景的 IndexedDB 库 `vocabflash_wallpapers_v1` 及旧背景设置。**不会删除词库和学习进度**。
- 7 张背景都加入 Service Worker 的离线缓存，缓存版本升级至 `vocabflash-cache-v5`。
- 没有增加或导入任何 2016 年 / 2024 年四级词汇；遵循用户要求，等所有年份真题发齐后才统一合并导入。

## 如何在 Windows 上替换 GitHub Pages 文件

1. **先备份词库**：在 iPhone 已安装的 VocabFlash 中，点「词库管理 → 导出备份」，保存导出的 JSON。**不要删除主屏幕 App 或清除 Safari 网站数据**。
2. 在 Windows 上解压 `VocabFlash_PWA_v5_七张背景_每分钟随机.zip`。
3. 打开 GitHub 的现有 `vocabflash` 仓库，在最外层（原来有 `index.html` 的位置）点击 **Add file → Upload files**。
4. 将解压得到的 **13 个文件**全部选择后上传：
   - `index.html`、`manifest.json`、`sw.js`、`README.md`
   - `icon-192.png`、`icon-512.png`
   - `wallpaper-01.jpg` 至 `wallpaper-07.jpg`
5. 点击 **Commit changes**。所有 JPG 和 HTML/JS 都放在**仓库根目录**，不能只上传 ZIP 或额外套一层文件夹。
6. 等 GitHub Pages 完成部署。用 iPhone 的 **Safari** 打开原来的网站地址并刷新，再从主屏幕重新打开 VocabFlash。切到「背景图片」，应显示「专属轮换背景 · 7 张」。
7. 如仍显示旧版，关闭主屏幕上的 App，在 Safari 打开网址并重新加载，等 Service Worker 更新后再打开。不要为了刷新而清理 Safari 网站数据。

> 如果 GitHub 提示同名文件不能直接上传，请把提示截图发给 AI 助手，不要删除仓库或清理手机数据。

## iPhone 使用方法

- 「背景图片」默认选「**每 1 分钟自动随机**」；维持这个选项就不用设置。
- 「立即换一张」可以手动更换。
- iOS PWA 在后台可能暂停计时器：**关闭 / 锁屏时不保证每分钟更换**；重新回到前台时，会检查切换时间。
- 只有这七张图片；此版不提供手机上传其他背景的按钮。如以后想加入更多图片，可以交给 AI 助手更新内置图片包。

## 技术及隐私说明

- 本版的所有图片以 GitHub Pages 同源静态文件提供。公开的 GitHub Pages 网站上，**这些图片文件可以被任何知道站点地址的人查看**，不要把需要保密的照片放进公开仓库。如果你不希望人物照片公开，请**先不要上传**这个版本。
- 词库仍保存在旧版的 `localStorage` 键 `vocabflash_pwa_v1`；JSON 备份仍保留旧结构（包括 `spellingProgress`）。图片不属于词库 JSON 备份。
- 首次访问新版需要联网下载文件，之后缓存正常建立才能离线使用背景。
- 本包已做代码静态校验、模拟浏览器交互与离线逻辑模拟测试；**尚未在你的真实 iPhone/GitHub Pages 上验证**。
